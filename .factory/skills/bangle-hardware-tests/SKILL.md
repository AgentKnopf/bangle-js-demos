# Bangle hardware tests

Read `AGENTS.md`, then `hw-tests/AI-GUIDE.md`, then the selected app's
`apps/<id>/HW-TESTS.md`. Follow the guide's local BLE setup, first-contact,
installation/readback checks, session order and cleanup.
Give the human one action at a time and wait for confirmation and measurements.
Never assume hardware results. Ask before disruptive steps or publishing results.
Keep this entry point thin; the guide is the single workflow source.
